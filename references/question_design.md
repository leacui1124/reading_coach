# 问题设计指南

## 10 个问题的层次结构

好的反问式教练对话，问题应有递进层次：

| 层次 | 问题类型 | 目的 | 示例 |
|------|---------|------|------|
| Q1-Q2 | **概念澄清** | 确认读者对核心概念的理解是否准确 | 「你怎么理解'造钟人'？」 |
| Q3-Q4 | **因果追问** | 挖掘概念背后的逻辑 | 「为什么乔布斯被误判为报时人？」 |
| Q5-Q6 | **反例检验** | 用边界条件测试理解深度 | 「亚马逊是长坡厚雪吗？为什么？」 |
| Q7-Q8 | **迁移应用** | 把理论拉回读者的现实 | 「你投资或经营的某个公司，用这个框架怎么评估？」 |
| Q9** | **整合串联** | 把多个概念连接成框架 | 「这三个概念之间是什么关系？」 |
| Q10 | **行动导向** | 读者学完最该做什么 | 「你最需要改变的一件事是什么？」 |

## 指正读者偏离的话术

当读者回答跑偏时，使用以下模式：

```
[说明偏离]
你的理解方向[对/有一部分对]，但你说的[X]其实偏离了书本的核心。

[回归核心]
段永平（或作者）在这里强调的是……

[重新聚焦]
让我们回到这个问题：[重述问题或提出更精准的版本]
```

**常见偏离类型**：
1. **概念混淆**：把 A 概念的特征错误套用到 B 上
2. **因果倒置**：把结果当原因，或把原因当结果
3. **过度泛化**：用一个特例来否定规律
4. **自说自话**：完全没有回应书中的观点，只讲自己的经验

## 问题质量检验清单

生成问题前，用以下清单检验每个问题：

- [ ] 这个问题有唯一正确答案吗？（好问题通常有）
- [ ] 这个问题能考察读者是否真的读懂了，而不是只会背诵？
- [ ] 这个问题能触发读者的实际反思？
- [ ] 这个问题是否和读者的身份/行业有连接？
- [ ] 问题描述清晰，不会引发歧义？

## 访谈问题设计原则

访谈问题（第七步）不同于阅读反问，需要满足：

1. **受众关注度高**：目标受众真的有这个困惑
2. **澄清价值**：能帮助澄清互联网上常见的误解或认知盲点
3. **内容可复用**：回答后可直接转化为文章、短视频、直播话题

**好访谈问题示例**（面向中小企业主受众）：
- 「很多老板觉得'只要产品好，利润自然来'，但现实往往相反。你怎么看这个问题？」
- 「你怎么判断一家公司值得长期投入，而不是快速捞一票就走？」

**差访谈问题示例**：
- 「你觉得段永平这本书怎么样？」（无澄清价值）
- 「企业文化重要吗？」（太泛，答案显然）

## 爆款选题结构模板

访谈结束后，生成爆款选题，每条选题按以下格式：

```
📌 选题 [N]：[标题]
核心角度：[这个选题戳中了受众的什么痛点/认知盲点]
内容方向：[1-2 句话描述可以怎么写/拍]
书中依据：[引用书中哪个核心观点支撑这个选题]
```
